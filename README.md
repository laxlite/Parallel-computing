## Описание
Репозиторий с домашними заданиями по курсу **Операционные системы**.  

## Содержание

| Директория               | Тема                                                                |
| ------------------------ | ------------------------------------------------------------------- |
| `async_delegates`        | Применение делегатов.                                               |
| `asyc_timeout`           | Ожидание завершения асинхронного метода с использованием тайм-аута. |
| `continue_tasks`         | Задачи продолжения.                                                 |
| `reverse_async_callback` | Использование обратных асинхронных вызовов.                         |
| `tasks_101`              | Создание и запуск задач.                                            |
| `thread_101`             | Применение класса Thread.                                           |
| `thread_args`            | Передача данных потокам.                                            |
| `thread_types`           | Типы потоков. Управление потоками.                                  |

## Стек

- Язык программирования: C#
